# 应用图标：A1「会话行」定稿

图标是一张会话表：四行，第二行是蓝色选中行，第三行带一段黄色搜索命中。颜色取自 `style.rs`：accent `#2563eb`，命中黄 `#f5b83d`（比界面里的 `hit_bg` 深，否则在白底上看不清）。16 / 32 px 用简化版：三行、线条加粗，命中画成整根黄条。

## 怎么选出来的

候选画布：https://claude.ai/artifact/4o4cZdziPo2xK9E4w3EKBx（Design Artifact，仅自己可见）。

- 第一轮六个方向：A 会话行、B 步骤刻度、C 检索镜、D 回合括号、E 会话卡片、F asm 终端。画布下方的「尺寸与场景对比」把它们放进浅色和深色 Dock，并给出 128 / 64 / 32 / 16 的尺寸梯度。
- 选定 A 之后又出了五个变体：A2 表头加徽章、A3 深色、A4 蓝底反白、A5 小尺寸简化、A6 加放大镜。用户认为 A1 原版最平衡，选它做主图；16 / 32 px 采用 A5 的结构。

## 文件与生成

- `assets/icon/app-icon.svg`：主图，用于 64 px 及以上。方形在 Apple 的 1024 网格上，824 px 宽、四周留 100 px，底部带一层投影。
- `assets/icon/app-icon-small.svg`：16 / 32 px 用。所有边都在 32 的倍数上，所以 32 px 时每条边都落在整像素上。方形是主图的方形按这个网格取整：832 宽、四周留 96，在 32 px 时是 26×26、留 3 px。
- `make icon`（`scripts/make-icon.py`，uv 装 `resvg-py` 渲染）：输出 `.iconset` 到 `tmp/icon/`，再用 `iconutil` 打包成 `assets/icon/AppIcon.icns`，生成结果提交进仓库。改了 SVG 之后要重新跑。

## macOS 26 下的显示（2026-10-28 实测，macOS 26.7.1）

macOS 26 会把形状不合规的旧式图标缩小，放进灰色的方形底框里（俗称 icon jail）。验证方法：在 `tmp/` 里拼一个只带 `.icns` 的最小 `.app`，用 `lsregister` 登记，再用 `NSWorkspace.icon(forFile:)` 取出系统实际画的图标，最后注销登记。

- 64 / 128 / 512 px：没有被套框。系统套上了自己的方形遮罩和边缘高光，大小和自带的计算器一致。
- 16 / 32 px：被套了框，但这个结果说明不了问题。把 Karabiner-Elements 原样的 `.icns` 放进同样的测试 bundle，结果完全一样；而 Karabiner 装在 /Applications 里时，各尺寸都正常。也就是说，这是测试方法（未签名、从没启动过的临时 bundle）造成的。
- 参照其他只带 `.icns` 的应用：16 px 时方形都是 12×12、留 2 px；32 px 时 Lark、ImHex 用 26×26、留 3 px，Karabiner 用 24×24、留 4 px。我们的 32 px 和前者一致。16 px 我们是 14×14，边缘有半像素的虚边，只在非 Retina 屏上出现。

## M5 打包时要核对

- 把 `AppIcon.icns` 放进 `Contents/Resources`，Info.plist 写 `CFBundleIconFile`。签名之后看 Finder 列表视图和 Dock 里的小尺寸有没有灰框。
- 如果仍然被套框，就改用 Icon Composer 的 `.icon` 格式（本机 Xcode 27.1 带 Icon Composer 和 `actool`），编译成 `Assets.car`，Info.plist 写 `CFBundleIconName`。
