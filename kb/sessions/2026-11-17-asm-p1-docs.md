## known-issues

新增 6 条（标题）：

1. 会话表与 asm：闲置会话被 Claude Code 追加记录后，更新时间变成刚才（P1-4 R1 #4，P1-7 F1 实证）
2. asm：在 app 里换了收藏目录后，`asm` 的命令都报 RootsChanged 失败（P1-4 R1 #2）。核对代码：`asm` 是 exit 1；app 遇到这种情况会自动整库重建。
3. 索引：app 打开或写索引失败后，扫描和重建请求被悄悄丢掉（P1-1 R1 #4、R2 #1、复核 R2-4、R4 #3）。「打开失败后线程退出」和「asm 冷建时 app 写库 busy」是同一类问题，按 status 的建议合成一条，并写明开发期只在共用索引时才碰得到。
4. asm：重建索引的头几秒里启动的 `asm` 用几乎空的索引作答，不提示（复核 R3-1、R4 #1）
5. 索引：`--db` / `ASM_DB` 指错文件时，别的程序的 SQLite 库会被清空（复核 R2-3）
6. asm：app 写账本时，`asm` 要等 5 s 才回退（决定 28）

更新 1 条：「搜索：正则扫描远超 500ms 目标…」改名为「扫描原始文件的搜索慢…」。原内容保留，加上新 `asm search` 的预过滤和 P1-3、P1-7 的实测（F4），处理方向改为「把预过滤接到 app 和 `search-old`」。
