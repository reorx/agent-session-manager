## 概要

把 history 的原分组逻辑抽成 `group_history`，表格摘要与详情 prompt 列表共用它，保持有 ID 聚合、匿名组相邻时间差大于两小时才切组的行为。详情每条记录先还原粘贴再清理文本，保留命令和空文本，避免详情条数与表格计数不同。

History 对话每条 prompt 对应一个编号回合，只有时间与 prompt，没有回复、步骤、附件或耗时，结束状态为 `NoReply`。复用 `Marked::new` 的截断、中文 UTF-8 命中区间和命中窗口移动，`hit_places()` 照常提供导航位置。来源标志供后续 app 隐藏状态灯、刻度和缺失回复提示。

导出和完整对话读取共用 `is_interruption`，识别 `interruptedMessageId` 或去掉首尾空白后以 `[Request interrupted by user` 开头的文字。导出忽略这条用户标记，不另起一轮，已记录的回复和工具计数继续沿用现有规则。

## 接口清单（给 asm-m4b-actions）

- `model::HistoryPrompt { pub ts: i64, pub text: String }`：Unix 毫秒与清理后的文本，派生 `Clone, Debug, PartialEq, Eq`，亦可从 `claude::history::HistoryPrompt` 导入。
- `claude::history::HistoryGroup<'a> { pub id: String, pub id_known: bool, pub rows: Vec<&'a HistoryRow> }`：借用原行，避免复制粘贴内容。
- `claude::history::group_history<'a>(project_key: &str, rows: &'a [HistoryRow]) -> Vec<HistoryGroup<'a>>`：输入保持文件顺序，返回稳定分组。
- `claude::history::history_prompts(claude: &ClaudeDir, project_key: &str, session_id: &str) -> anyhow::Result<Vec<HistoryPrompt>>`：读 history、精确匹配项目和完整组 ID，再恢复及清理每条 prompt。
- `claude::conversation::conversation_from_history(prompts: &[HistoryPrompt], matcher: Option<&Matcher>) -> Conversation`：纯转换，卡片编号从 1 开始，`ts` / `last_ts` 均为 prompt 时间。
- `model::Conversation::history_only: bool`：History 为 true，transcript 为 false；app 转换层需将它传入视图，目前尚未接线。
- `transcript::is_interruption(record: &Record, text: &str) -> bool`：仅 crate 可见，供导出与 conversation 共用。

## 注意事项与自己的决定

- 按仓库 core 规则，公开 prompt 类型的唯一定义在 `model.rs`，而不是 spec 写的 `history.rs`；重导出保留 spec 路径可用性。
- 在整个 Conversation 上标记 History，避免每回合冗余字段，也能覆盖空 History；普通 transcript 的所有调用默认 false。
- History 的 `bytes` 和 `skipped_lines` 为 0：没有 transcript 文件；`load_history` 本身忽略坏行，当前接口不提供坏行计数。
- history 文件、项目或 session 不存在时返回空列表；其它读取错误向上传递。加载与分组沿用现有规则，不重新排序、不去重、不过滤斜杠命令。
- 打断过滤在导出取 human_text 时执行；没有修改索引、Prompts 口径或 shared is_human_input 的定义，完整对话仍先处理 compact / tool_result 再判打断。
- 没有升级 schema、增加依赖、改分支或 push。未提交另一个执行者的 resume 总结。
