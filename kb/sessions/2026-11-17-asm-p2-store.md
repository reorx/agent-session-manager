## 实现与计划修订

`cache-health.md` 已落实 T1–T16 和决定 34–37：自然日 / 滚动时间、调用模型过滤、nullable 与 ID 模式错误契约；核心 Reader 所属与完整事件接口、首次缓存 / 末次计费分离、跨断点祖先恢复、两组 RecordFilter、无 ID / 重复 ID 请求顺序、按来源长度、指纹不跨版本持久化、生命周期、真实组件名称、AUTO 编号、扫描 / 查询性能边界、冻结审计基准。步骤 1、2 标注 P2-0 日期与证据，步骤 3 由本提交交付。

保存有序事件而不是最终图：后面出现的同 UUID 或同请求 ID 不能改变早先调用当时看到的状态。每条可解码记录先投影为不含正文的事实；有 uuid 的 Node 也保存，sidechain 和重复记录在重放时统一过滤，被排除的 uuid 仍占据所属去重组。没有 uuid 且没有缓存语义的记录不存；blob 内容、tool 正文、request tail 正文均不存。

请求存原 shape 字符串与排序去重后的 beta 集合，重放时才计算与 Reader 相同的哈希，避免 DefaultHasher 跨版本稳定性和 u64→SQLite 符号位问题。缺时间保持 None，speed 缺失不反推 standard。请求缺 id 仍推进对应 querySource 的 last_len，重复 id 只对之后的调用生效。

`CacheTracker` 与 `conversation.rs` 生产代码完全不变。新 `claude/cache_events.rs` 负责投影和重放；`Feed` / `ParsedTranscript` 带 cache_events；`index/cache.rs` 提供存取与刷新。`write_parsed` 在既有单写事务内先写会话、用量与事件，再重写派生表；非 Append 清旧缓存，文件缺失保留缓存事实与已有编号，真删 / clear_all / schema 重建通过外键级联清理。subagent 只走原用量路径。

`sessions` 与 api_usage 的列未变，因此 SESSION_COLUMNS / row_to_session 列序原样正确；账本、pricing、session_model_usage、UsageRow::prompt_tokens 均未修改。schema 8 的理由写在版本号旁。

## P2-2 接口交接

- `Db::cache_events(session)`：原始顺序事实，按 byte_offset。
- `Db::cache_calls(session)`：`IndexedCacheCall { byte_offset, turn, parent_msg_id, facts }`；facts 为首条合格响应的 model / nullable ts / effort / speed / request_id / 全部计费 Tokens / 判定 prompt / read。
- `Db::cache_breaks(session)`：`IndexedCacheBreak { msg_id, byte_offset, turn, model, rebuilt }`，完整原 CacheBreak 与附带原因值。
- `Db::refresh_cache_breaks(session)`：仅从已存事件重放；生产调用应置于 Db::transaction 内，与 refresh_session_usage 相同。
- SQL `cache_calls` 有 model / ts / turn / parent_msg_id / prompt_tokens / prompt_cache_read，`cache_breaks` 有 ts / model / dropped / written / cost_usd / cause；data 保存完整强类型 JSON，附带 from/to/on/gap/ttl 不丢失。时间和位置索引已建；P2-2 聚合可直接使用这些标量列。
- SQL 原因码是 `model_switch`，冻结 TSV 的码是 `model`；`sign_in` 与 `request_settings` 分列两个码，公开 enum 仍是 RequestSettings { sign_in }。
- token / 总 Hit% 沿用 api_usage，含 subagent；缓存首条快照专供 --calls 与判定。异常分块 usage 不一致时两者可能不同，这是保留原 Reader 与计费各自语义。
- turn 在事件重放时产生，AUTO、命令输出卡与首 prompt 前均为 None，文件缺失后仍可重现；不能再按 messages 数量覆盖这个值。
